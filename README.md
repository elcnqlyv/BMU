# Bit Manipulation Utility

A small C program for practicing bitwise operations on unsigned integers.

The program allows a value to be viewed and modified one bit at a time.

## Features

* Set an integer value
* Display the value in decimal
* Display the value as 32-bit binary
* Set a bit
* Clear a bit
* Toggle a bit
* Check whether a bit is set

## What I practiced

* Bitwise AND, OR and XOR
* Bit shifting
* Bit masks
* Unsigned integers

## Build

```bash
gcc bit-manipulation-utility-main.c -o bmu
./bmu
```
